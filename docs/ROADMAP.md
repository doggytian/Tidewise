# Tidewise 路线图

> 制定日期：2026-09-30。本文件中的**验收标准与事先承诺**须在看到对应阶段的研究结果之前确定；
> 如需修改，必须在提交说明中写明原因，且不得以"结果不好看"为由放宽。

## 1. 项目定位

**系统化交易参谋 + 风控纪律工具**，而不是全自动交易机器。

每个交易日收盘后告诉使用者：各品种信号、应持手数、当前风险占用、需要执行的调仓清单；由人确认后执行。
价值排序：**仓位与风险纪律 > 前向业绩记录 > 信号本身 > 自动执行**。

理由（来自 P2 回测证据，2019-06 ~ 2026-09，11 品种，30 万）：
- 单一 EWMAC(16,64) 年化 1.79%、最大回撤 -31%、夏普 0.11；成本（手续费+滑点+换月）约占毛利一半。
- 7 年样本下夏普估计标准误约 0.38，回测无法证明策略有效或无效，**只有前向记录能**。
- 日线频率每日 0~5 笔委托，自动执行省时有限，却引入断线、重复下单、状态不一致风险。

## 3. 阶段 A：研究可信化

| 任务 | 内容 |
|---|---|
| A1 延长历史 | 逐合约日线延长至约 2010 年（交易所日线接口；DCE 需另找来源），与新浪数据交叉校验 |
| A2 稳健信号组合 | 多速度 EWMAC (8/32, 16/64, 32/128, 64/256) + carry，等权合成；**配置在看样本外结果前冻结** |
| A3 小资金适配 | 按单手资金波动筛选品种；整数手约束下的仓位优化；组合层波动目标；降低换手 |
| A4 账户级风控 | 总保证金占用上限、单品种上限、回撤熔断、kill switch |

**研究纪律**
- 样本划分：2010 ~ 2018 为研究样本，2019 ~ 至今为样本外，**样本外只看一次**。
- 不做参数网格搜索；只允许使用文献中的标准参数。
- 所有回测必须扣除手续费、1 跳滑点与换月成本。

**验收**：样本外净夏普 > 0.3，且最大回撤优于 -20%，且单年最大亏损优于 -15%。
**未通过**：不进入 B；记录结论，回到研究或将项目降级为纯研究平台（角色 C）。

## 4. 阶段 B：每日决策报告（第一个可用交付）

- 收盘后自动运行：数据更新 → 信号 → 当前主力合约目标手数 → 与持仓比对 → 调仓清单 → 保证金/风险占用。
- 持仓来源：手工录入（YAML/CLI），后续可接 CTP 只读查询。
- 账户级风控结论写进报告（触发熔断时明确"今日不开新仓"）。
- 支持录入主观交易想法，由系统给出建议手数与风险占用。
- 推送：飞书（长连接，不开放公网端口）；控制台作为兜底。

**验收**：连续 20 个交易日自动产出报告，零人工修数据；报告目标手数与回测同日目标一致。

## 5. 阶段 C：前向跟踪

- 按报告执行，使用仿真账户或极小资金；每日记录"建议 vs 实际执行"。
- 统计：实际滑点、执行偏差、前向业绩与回测分布的偏离。

**验收**：满 6 个月；实际平均滑点 ≤ 回测假设；回撤在 §7 预算内。

## 6. 阶段 D：自动执行（可选）

- vn.py + `vnpy_ctp`；先 openctp 仿真，再小资金实盘；复用 `tidewise.plan` 半自动审批状态机。
- 前置：完成期货公司程序化交易报备。

## 7. 事先承诺（资金规则）

| 规则 | 内容 |
|---|---|
| 首次实盘 | 仅在 C 验收通过后；起始资金不超过计划总额的 1/3 |
| 加仓 | 每满 6 个月且回撤在预算内，方可加至下一档 |
| 停用 | 实盘回撤超过 -20% 立即停止交易，回到研究阶段；**不在回撤中修改参数** |
| 预期 | 多品种趋势策略公开长期表现：夏普约 0.3 ~ 0.7，年度回撤常见 20% ~ 30%，可能连续 1~2 年不盈利 |

> 本项目为个人研究工具，不构成投资建议。
